# Sprint_6

Проект по автоматизации UI-тестов для сервиса «Яндекс Самокат»

# Тестовые сценарии

1. Выпадающий список в разделе «Вопросы о важном».  
   Проверить: при клике на стрелочку открывается соответствующий текст.  
   Важно написать отдельный тест на каждый вопрос.

2. Переходы по логотипам.  
   - Клик по логотипу «Самоката» ведёт на главную страницу «Самоката».  
   - Клик по логотипу «Яндекса» открывает главную страницу Дзена в новом окне.


3. Заказ самоката.  
   Позитивный сценарий с двумя наборами данных.  
   Проверить точки входа в сценарий: кнопки «Заказать» вверху и внизу страницы.

4. Окно подтверждения заказа.  
   Нажать кнопку «Заказать» → в попапе нажать «Да» → убедиться, что заказ успешно создан.

5. Заполнение формы заказа.

6. Успешное создание заказа.  
   Проверить, что появилось всплывающее окно с сообщением об успешном создании заказа.
